# Protótipo do novo site do IPAC

Protótipo para avaliação da Diretoria do IPAC — Instituto de Preservação Ambiental e Conservação (Tangará da Serra – MT).
Conteúdos marcados como provisórios dependem de confirmação. Os formulários (contato e novidades) funcionam apenas na hospedagem oficial com PHP.

Versões: português (raiz), [inglês](en/) e [espanhol](es/).
